### Expense Tracker REST API

<p>
<img src="https://img.shields.io/badge/Spring_Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white" />
<img src="https://img.shields.io/badge/Spring_Security-6DB33F?style=flat-square&logo=spring-security&logoColor=white" />
<img src="https://img.shields.io/badge/PostgreSQL-316192?style=flat-square&logo=postgresql&logoColor=white" />
<img src="https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black" />
</p>

An enterprise-style backend for personal expense and budget management, built around **~24 REST endpoints** across Auth, Category, Expense, Budget, and Reports/Analytics modules.

- JWT-secured authentication and authorization via Spring Security
- Category-based filtering, CSV export, and budget tracking with a clean Controller → Service → Repository architecture
- Vanilla HTML/CSS/JS frontend with an emerald-and-slate design system, including a redesigned pill-style "Add Transaction" flow

**[View Repository »](https://github.com/shahzaib111-nu/Expense_Tracker)**

### EduScan QR Attendance System

<p>
<img src="https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask&logoColor=white" />
<img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" />
</p>

A QR-based attendance system with a built-in anti-fraud layer.

- WiFi proximity verification alongside QR scans, so attendance can't be marked off-site
- Excel roster integration for fast class setup
- Designed to close the proxy-attendance loophole common in simpler QR systems
